# Синтетический граф для проверки

После запуска генератора `check/` содержит 21 вымышленный 18-значный `gid`, 19 направленных рёбер и 26 транзакций за июль 2026 года. Формат трёх parquet совпадает с исходным набором. Суммы и количество транзакций на рёбрах согласованы с отдельными переводами; все переводы не меньше 5 000 KZT. Данные не относятся к реальным клиентам и не являются разметкой мошенничества.

Проверяемые узлы (полный `gid` = `180000000000000000` + суффикс):

| Суффикс | Сценарий | Ожидаемая роль |
|---:|---|---|
| 1 | Seed с тремя исходящими ветвями | `distributor` |
| 104 | Три входа и один выход | `consolidator` |
| 201 | Промежуточный перевод дальше по цепочке | `transit` |
| 202 | Сходящиеся и расходящиеся ветви | `coordinator` |
| 101 | Получатель без исходящих переводов на первом колене | `terminal` |
| 401 | Узел без видимого выхода на четвёртом колене | `peripheral`, ограничение наблюдения |
| 5 | Изолированный seed | `peripheral`, низкое качество наблюдения |

Воспроизвести файлы:

```powershell
track02/.venv/Scripts/python.exe track02/fixtures/generate.py
```

Рассчитать результаты по проверочному набору и открыть их в интерфейсе:

```powershell
track02/.venv/Scripts/python.exe track02/pipeline.py --data track02/fixtures/check --out track02/out
node server.mjs
```

Откройте <http://127.0.0.1:4173> и найдите любой указанный `gid`. Кнопка «Пересчитать модель» снова использует исходный набор из `track02/data/`; чтобы вернуть его результаты без интерфейса, запустите `track02/.venv/Scripts/python.exe track02/pipeline.py --data track02/data --out track02/out`.

Автоматическая проверка сценария:

```powershell

```
