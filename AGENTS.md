# Инструкции для Codex

## Цель

Помогать команде быстро довести идею до работающего MVP и короткого убедительного демо.

## Ограничения

- Работай с файлами только в этой папке.
- По указанию владельца итоговая ветка — `main` (ранее `test-arman`). Отправляй проверенные изменения в существующий репозиторий команды в `main` не реже одного раза в час. Не создавай удалённые репозитории, не публикуй сайт и не создавай PR.
- Не добавляй внешние зависимости без явной необходимости.
- Сохраняй приложение запускаемым командой `node server.mjs`.
- После изменений запускай `node --test`.

## Приоритеты

1. Рабочий главный сценарий пользователя.
2. Надёжное демо без ручных обходов.
3. Понятный питч и измеримая ценность.
4. Визуальная полировка после проверки сценария.

## Стиль кода

- Используй понятные имена и небольшие функции.
- Не помещай секреты и ключи в файлы проекта.
- Обновляй README, если меняется способ запуска.
