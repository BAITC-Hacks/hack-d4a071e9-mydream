## Текст для формы

**Название:** Money Graph — объяснимая карта финансовых связей.

**Описание:** Локальный инструмент для AML аналитика: преобразует три Parquet-файла с исходящими переводами на четыре колена в направленный граф, объяснимые ролевые гипотезы для каждого из 2 248 узлов, кластеры и топ-50 приоритетов проверки. Учитывает обрыв на четвёртом колене и неполноту входов исходных клиентов. Показывает конкретные переводы, вклад каждого признака, ограничения наблюдения и экспортирует три CSV фиксированной схемы. Основной расчёт работает без внешних сервисов; дополнительный GPT-6 Sol поясняет ограниченный контекст графа при наличии разрешённого API-доступа. Критерии, воспроизводимый запуск, схема решения и пятиминутное демо доступны в README репозитория.
