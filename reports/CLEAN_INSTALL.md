# Проверка установки в новом окружении

23 сентября 2026 года проверен коммит `b9d931783ba59298a2147e1b6a59186bebf542ad` перед переносом в `main`. Функциональный код при переносе не менялся.

## Условия

- Windows x64, CPython 3.12.14, Node.js 24.19.0.
- В отдельную папку перенесён 61 файл коммита. Git blob SHA-1 каждого файла, включая исходный архив данных, совпал с деревом GitHub.
- Исключены старые `.venv`, `.deps`, распакованные данные и результаты расчёта. Создано новое окружение без системных пакетов.
- Данные распакованы из `track02/materials/data.zip` командой README.
- Зависимости установлены только из `track02/requirements.txt` через `pip --isolated install --no-cache-dir --index-url https://pypi.org/simple`. Загружены новые wheel-файлы.
- Проверено, что NumPy, pandas, DuckDB и NetworkX импортируются из нового окружения. `pip check` сообщил `No broken requirements found`.
- Для серверных проверок API-ключ отсутствовал; использован свободный порт 4182. Рабочий сервер пользователя не перезапускался.

## Пределы проверки

Проверена новая установка зависимостей и приложения на существующей Windows. Установка самой ОС, Python и Node, а также запуск на Linux/macOS отдельно не проверялись. Для первичной установки нужны доступ к закрытому репозиторию и интернет до PyPI. После установки обязательный сценарий работает локально; опциональному Sol нужен разрешённый API-ключ с доступом к модели. Живой вызов Sol в этой проверке не выполнялся.
